5. Bug Fixes & Live Determination Mandate

The "Lucia Szabová" Bug: You noticed Lucia Szabová was recorded fighting herself in the library. This occurred because DraftKings buttons on upcoming multi-bout cards shared an ancestor container, causing DOM traversal to assign the same fighter name to both buttons. Combined with pre-fight odds pushing, it created a phantom recording.

The 4-Tier Fix Implemented:

  • Aria-Label Inspection: Reads exact names directly from DraftKings native button accessibility labels.
  • Header Matchup Fallback: Disambiguates identical names using the event title header (Fighter A vs Fighter B).
  • Strict Live Filter: The extension now strictly requires active DraftKings in-play indicators (LIVE badges, running clocks, round numbers, or your manual button) before streaming to the recorder. Pre-fight browsing will never pollute recordings again.
  • NFD Unicode Normalization: Strips accents cleanly so "Szabová" and "Szabova" are reconciled identically.
